# Codemap — "where is X?"

```
lib/
  main.dart                 Hive init, adapter registration, box opening, locator, runApp
  app.dart                  MyApp: providers, blocs, MaterialApp, theme, routes
  router/routes.dart        AppRoutes constants (/splash /onboarding /home /surah /juz /bookmarks /shareApp /page)
  router/router.dart        appRoutes map + global navigator key
  services/locator.dart     get_it registrations (data provider → repos → blocs)
  blocs/{chapter,juz,bookmarks}/   bloc.dart + event(s).dart + state.dart (part files)
  providers/                AppProvider (theme, firstOpen, Hive 'app' box), OnBoardingProvider (page index)
  configs/                  App.init + UI, AppDimensions, Space, AppTheme, AppText, UIProps, extensions
  ui/screens/<name>/        <name>_screen.dart + widgets/ (part files)
      splash/ onboarding/ home/ surah/ page/ juz/ bookmarks/ share_app/
  ui/widgets/               shared widgets (app/, button/, core/screen/, headless/, loader/, misc)
  ui/animations/            WidgetAnimator (bottom_animation.dart), EntranceFader
  static/assets.dart        StaticAssets constants (generated by scripts/assets.dart)
  static/hive.dart          AppHiveTypes (mirror of the api package's typeIds — keep identical)
  utils/drawer.dart         DrawerUtils.items (drawer entries → routes)
  utils/juz.dart            JuzUtils.juzNames (30 Arabic juz names)

packages/al_quran_api/      Dio client (src/services/http), models (src/models/{ayah,chapter,juz}),
                            data provider (src/data_providers), AppHiveTypes (src/static/hive.dart),
                            build.yaml (json_serializable options), hive_registrar.g.dart (generated)
packages/al_quran_repo/     repos (src/repos/impls) + interfaces (src/repos/interfaces)

test/blocs/                 bloc tests   test/widget/screens/   widget tests   test/helper/   mocks, tester extensions, hive helper
android/                    Kotlin DSL Gradle, MainActivity.kt, manifests, key.properties (ignored)
ios/                        Runner project, Podfile (deployment target 15.0)
web/                        index.html, manifest, icons (build is broken — see platforms/web.md)
assets/{images,intro,logos} fonts/ (Poppins*, noor-regular)
_templates/                 hygen generators (screen, provider usable; cubit templates stale)
scripts/assets.dart         regenerates lib/static/assets.dart
.github/workflows/run_test.yml   CI: analyze + test on PRs to master
.fvmrc                      pinned Flutter version
docs/                       this knowledge base
.agents/ (.claude → symlinks)  rules + skills
```
