# Flutter / Dart rules (app code)

Enforced on every file under `lib/`. Full reference: `docs/conventions/dart.md`, configs API in `docs/architecture/configs.md`.

## Widgets
- **Never return a widget from a function or getter.** Always a class: `class _Body extends StatelessWidget`. The only `Widget`-returning method is `build(BuildContext)`.
- Screen-private widgets live in `lib/ui/screens/<screen>/widgets/` and are wired with `part '../<screen>.dart'` / `part 'widgets/x.dart'` (see `home_screen.dart`). Shared widgets live in `lib/ui/widgets/` — check what exists (`Screen`, `AppButton`, `AppBackButton`, `CustomTitle`, `CustomImage`, `LoadingShimmer`, `WidgetAnimator`, `Flare`, `QuranRail`, `Calligraphy`) before building a new one.
- Every screen body goes through `Screen` (`lib/ui/widgets/core/screen/screen.dart`) — it wires `App.init`, status-bar style, `PopScope`, `FocusHandler`.

## Configs layer (design tokens)
- First line of every `build()`: `App.init(context);` — it (re)initialises `UI`, `AppDimensions`, `AppTheme`, `UIProps`, `Space`, `AppText` for the current context.
- Colors: `AppTheme.c!.accent / primary / background / scaffold / text / textSub …`. Typography: `AppText.h1 … l2b` (+ `.cl(color)`, `.s(size)`, `.w(6)` extensions). Spacing: `Space.y1!`, `Space.h!`, `Space.xf(2)`, `Space.all(1)`; sizes via `AppDimensions.normalize(n)` / `.font(n)`. Radii/shadows: `UIProps`.
- Arabic Qur'an text uses `fontFamily: 'Noor'`; everything else inherits `Poppins` from the theme.
- `color.withValues(alpha: x)` — never `withOpacity`. Prefer tokens over `Colors.grey[850]`; legacy screens still do it, don't add more.

## Style
- `const` wherever possible; trailing commas on multi-line calls (`require_trailing_commas` lint); single quotes; `final` locals; no local type annotations where inferable (see `analysis_options.yaml`).
- Navigation: named routes from `AppRoutes` (`lib/router/routes.dart`), registered in `lib/router/router.dart`. `PageScreen` is the one exception (pushed with `MaterialPageRoute` carrying a `Chapter` or `Juz`).
- Assets: only via `StaticAssets` (`lib/static/assets.dart`, generated by `scripts/assets.dart`) — never string paths.
- `///` doc comments only for non-obvious *why*. No commented-out code left behind.
- Keep screens as assemblers (< ~300 lines); extract private widgets when they grow.
